# JioMart Clone

## Project Description

A full-stack e-commerce application inspired by JioMart. The application allows users to browse products, manage carts, place orders, and track purchases. Admin users can manage products and orders.

## Technology Stack

### Frontend

* React
* React Router
* Redux Toolkit
* HTML
* CSS

### Backend

* Node.js
* Express.js

### Database

* MongoDB
